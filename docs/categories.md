# ВЖИК — Categories & Attributes

Категорії зберігаються в БД (`categories`, `category_attributes`), повністю керовані з Admin Panel. Нижче — початковий seed-набір MVP (Category → Subcategory), що відтворює структуру вихідного документа. Sub-subcategory додаються по мірі потреби через Admin Panel без зміни коду.

## 1. Дерево категорій MVP

- **Дитячий світ**: одяг, взуття, іграшки, коляски, автокрісла, меблі, товари для новонароджених, шкільні товари, інше
- **Нерухомість**: продаж квартир, оренда квартир, продаж будинків, оренда будинків, земельні ділянки, комерційна нерухомість, гаражі, кімнати *(«подобова оренда» — див. DEC-01: пропонується окрема top-level категорія «Житло подобово», за зразком ринку)*
- **Авто**: легкові, вантажні, автобуси, мото, спецтехніка, сільгосптехніка, водний транспорт, причепи, будинки на колесах, електротранспорт, інше
- **Запчастини**: авто-, мотозапчастини, шини, диски, аксесуари, автоелектроніка, масла та рідини, інше
- **Електроніка**: телефони, планшети, ноутбуки, комп'ютери, комплектуючі, телевізори, фото/відео, аудіотехніка, ігрові приставки, смарт-годинники, побутова електроніка, мережеве обладнання, інше
- **Дім і сад**: меблі, побутова техніка, інструменти, сад та город, освітлення, будівництво, опалення, сантехніка, декор, текстиль, інше
- **Мода і стиль**: жіночий/чоловічий/дитячий одяг, взуття, сумки, аксесуари, годинники, прикраси, косметика, парфумерія, інше
- **Хобі, відпочинок і спорт**: спорт, туризм, риболовля, музичні інструменти, настільні ігри, книги, колекціонування, антикваріат, фото, відео, творчість, інше
- **Робота**: вакансії, пошук роботи, віддалена робота, підробіток, фриланс, стажування
- **Бізнес та послуги**: ремонт, будівництво, перевезення, прибирання, IT, дизайн, маркетинг, фото/відео, освіта, юридичні послуги, бухгалтерія, краса, послуги для тварин, інші послуги
- **Тварини**: собаки, коти, птахи, гризуни, риби, акваріуми, товари для тварин, ветеринарні послуги, інше
- **Оренда та прокат**: автомобілі, інструменти, техніка, одяг, спорядження, нерухомість, інше
- **Безкоштовно**: віддам безкоштовно
- **Обмін**: обмін товарами
- **Додатково (MVP+)**: книги та освіта, краса та здоров'я, продукти та фермерські товари, події та квитки, товари для бізнесу

Порівняно з фактичною структурою olx.ua (перевірено серпень 2026) склад категорій відповідає ринковим очікуванням; додатково варто розглянути «До речі, відомі речі» (вживані брендові товари) як promo-категорію на Phase 2 — не блокує MVP.

## 2. Модель атрибутів

`Category (1) → CategoryAttribute (N) → ListingAttributeValue (N, per listing)`

`CategoryAttribute.data_type ∈ {string, number, boolean, enum, multi_enum, range}`, `is_required`, `is_filterable` (визначає, чи атрибут доступний у фільтрах пошуку).

### Приклад: Авто → Легкові автомобілі

| key | label | type | required | filterable |
|---|---|---|---|---|
| brand | Марка | enum | так | так |
| model | Модель | enum (залежить від brand) | так | так |
| year | Рік випуску | number | так | так |
| mileage | Пробіг, км | number | так | так |
| engine_volume | Об'єм двигуна | number | ні | так |
| fuel_type | Паливо | enum | так | так |
| transmission | КПП | enum | так | так |
| drive_type | Привід | enum | ні | так |
| body_type | Кузов | enum | так | так |
| color | Колір | enum | ні | так |
| owners_count | Кількість власників | number | ні | ні |

### Приклад: Електроніка → Телефони

`brand, model, storage (enum), ram (enum), color (enum), condition (enum: new/used), sim_count (enum), warranty (boolean)`

### Приклад: Нерухомість → Продаж квартир

`area_sqm (number), rooms_count (number), floor (number), total_floors (number), building_type (enum), heating_type (enum), renovation_state (enum), is_furnished (boolean)`

Залежні атрибути (напр. `model` залежить від `brand`) реалізуються через `enum_options` з `parent_key` посиланням у JSONB-конфігу атрибута — не окрема таблиця в MVP, щоб не ускладнювати схему передчасно.

## 3. Керування з Admin Panel

Адміністратор: створення/редагування/видалення (soft) категорій і атрибутів, зміна порядку (`sort_order`), переміщення категорій (зміна `parent_id` з перевіркою відсутності циклів), масове редагування `is_filterable`/`is_required`. Видалення категорії з активними оголошеннями — заборонено (потрібно спершу перенести або заархівувати оголошення) — див. `decisions.md` DEC-03.
